# 📖 Visual Novel Introdutória (EM DESENVOLVIMENTO) 🌸

Uma Visual Novel interativa baseada em navegador, desenvolvida para entregar uma narrativa envolvente através de uma interface fluida e cuidadosamente estilizada com **Tailwind CSS**.

O objetivo deste projeto foi recriar a experiência imersiva dos jogos clássicos focados em história diretamente na web, unindo web design, estruturação de layout e desenvolvimento Front-End.

## ✨ Funcionalidades (Features)
- 🗣️ **Sistema de Diálogos:** Caixas de texto responsivas inspiradas na estética clássica de jogos do gênero.
- 🖼️ **Cenários e Personagens (Sprites):** Sobreposição e posicionamento preciso de imagens para imersão visual.
- 📱 **Design 100% Responsivo:** O layout se adapta para uma leitura confortável tanto em monitores ultrawide quanto em smartphones.
- 🎨 **Animações e Transições:** Uso de CSS para suavizar a entrada de personagens, troca de fundos e efeitos de texto.

## 🛠️ Tecnologias Utilizadas

A interface e o motor do jogo foram construídos utilizando:

*   **HTML5:** Estruturação semântica do "palco" do jogo, menus e elementos visuais.
*   **Tailwind CSS:** Framework *utility-first* essencial para acelerar a construção da UI, gerenciar o posicionamento rápido com Flexbox/Grid e garantir a responsividade diretamente nas tags HTML.
*   **CSS3 (Customizado):** Utilizado pontualmente para animações específicas e refinamentos visuais.
